AI 앱 연결

연결한 AI 앱

연결 가이드

쓰던 AI 앱에서, 사이드킥과 이어가요.

앱을 고르면 설정 위치와 연결 방법을 확인할 수 있어요.

현재는 시험 연결 안내예요. 실제 계정 연결과 공개 마켓 등록은 검증 중이에요. 사전 등록한 공개 클라이언트 ID와 정확한 HTTPS 복귀 주소가 필요하며, 주소만 복사하면 바로 사용할 수 있는 단계는 아니에요.

ChatGPT

시험 연결 · 사전 등록 필요

  1. ChatGPT 플러그인 설정을 열어요

    플러그인 설정 열기 ↗

    플러그인 관리에서 사용자 지정 연결을 추가하고 이름은 Sidekick, 인증은 OAuth로 선택해요. 계정에 따라 메뉴가 다를 수 있어요.

  2. 사이드킥 연결 주소를 복사해요

    원격 연결 주소를 입력하는 앱에서 사용해요. 인증 조건은 아래에서 확인해 주세요.

  3. 로그인하고 대화로 돌아와요

    발급받은 공개 클라이언트 ID와 ChatGPT에 표시되는 정확한 복귀 주소가 사전 등록돼 있어야 해요. 사이드킥 로그인·프로젝트 선택·권한 동의를 마친 뒤 대화에서 사이드킥을 선택해요.

ChatGPT 공식 안내 ↗

Claude

시험 연결 · 사전 등록 필요

  1. Claude 커넥터 설정을 열어요

    커넥터 설정 열기 ↗

    사용자 지정 → 커넥터 → 추가 → 사용자 지정 커넥터 추가를 열어요. 조직 계정은 관리자가 먼저 추가해야 할 수 있어요.

  2. 사이드킥 연결 주소를 복사해요

    원격 연결 주소를 입력하는 앱에서 사용해요. 인증 조건은 아래에서 확인해 주세요.

  3. 로그인한 뒤 커넥터를 켜요

    이름은 Sidekick, 인증은 로그인, OAuth 클라이언트는 자체 클라이언트 사용을 선택해요. 사전 등록한 공개 클라이언트 ID·복귀 주소로 동의한 뒤 대화에서 커넥터를 켜요.

Claude 공식 안내 ↗

Claude Code

인증 호환성 확인 중

  1. Claude Code의 연결 설정을 확인해요

    설정 방법 보기 ↗

    공식 문서의 HTTP 연결 방식과 /mcp 메뉴를 확인해요. claude mcp add --transport http 명령은 주소 등록 형식이며, 등록만으로 사이드킥 인증이 끝나지는 않아요.

  2. 사이드킥 연결 주소를 복사해요

    원격 연결 주소를 입력하는 앱에서 사용해요. 인증 조건은 아래에서 확인해 주세요.

  3. 로그인 복귀 방식을 먼저 맞춰요

    Claude Code의 로컬 로그인 복귀 주소와 사이드킥의 사전 등록 HTTPS 주소 정책을 맞춰야 해요. 호환성을 확인하기 전에는 로그인 성공이나 실제 사용을 보장하지 않아요.

Claude Code 공식 안내 ↗

Telegram

전용 봇 준비 중

  1. Telegram 연결은 봇 안내를 기다려 주세요

    봇 연결 방식 보기 ↗

    Telegram은 이 주소를 직접 붙여 넣는 연결 앱이 아니에요. 사이드킥 계정 연결을 지원하는 별도의 공식 봇과 안내가 필요해요.

  2. 공식 봇과 계정 연결을 확인해요

    현재 제공하는 봇 링크는 없어요. 이 웹 연결 주소는 Telegram 채팅에 붙여 넣는 봇 주소가 아니에요.

  3. 공식 봇이 준비되면 안내할게요

    지금은 공개된 사이드킥 봇 연결 경로를 안내하지 않아요. 봇 이름이나 링크를 임의로 만들지 않으며, 준비되면 로그인·권한 동의·채팅에서 요청하는 순서를 이곳에 제공할게요.

Telegram 공식 안내 ↗

연결을 마쳤다면 이렇게 요청해 보세요

“사이드킥에서 가능한 일과 필요한 연결을 알려줘”

작업을 맡긴 뒤에는 진행 상황을 묻고, 완료되면 결과와 사이드킥 작업 링크를 요청할 수 있어요. 채팅 안의 조작 화면이 없어도 텍스트와 링크로 확인해요.

권한 확인과 연결 해제

사이드킥 로그인 → 프로젝트 선택 → 읽기·일과 진행·수정 및 중단 권한 확인 → 동의 순서예요. 비밀번호나 비밀 키를 AI 채팅에 넣지 마세요. 유료 제작은 조건과 사용량을 따로 확인해요.

이 페이지에 로그인하면 “연결한 AI 앱”에서 해제할 수 있어요. 이미 접수한 작업은 별도로 중단해야 하며 결과는 사이드킥에 남아요.

연결이 안 되나요?

같은 사이드킥 계정인지, 연결이 사전 등록됐는지, 복귀 주소가 맞는지 확인해 주세요. 인증 화면이 만료되면 앱에서 연결을 다시 시작해요. 연결이 준비되지 않은 대상은 설정을 반복하지 말고 도움말로 문의해 주세요.

이 연결은 AI 앱의 구독을 사이드킥으로 옮기거나 별도 AI 엔진을 연결하는 기능이 아니에요. 연결 안내·실제 사용 검증·공개 마켓 등록은 서로 다른 상태예요.
